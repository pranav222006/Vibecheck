Django Project Codebase & Setup Guide

Complete reference files and Windows PowerShell commands for myproject / myapp.

Windows PowerShell Installation Instructions 

# 1. Open PowerShell in your project directory
cd C:\path\to\your\DjangoProjects

# 2. Activate existing virtual environment
.\.venv\Scripts\Activate.ps1

# 3. Install dependencies
pip install django requests python-dotenv pymongo

# 4. Make and apply database migrations
python manage.py makemigrations myapp
python manage.py migrate

# 5. Create superuser (Admin access)
python manage.py createsuperuser

# 6. Run the local development server
python manage.py runserver 8000
